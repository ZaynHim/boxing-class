## Overview

IronFist Boxing is a multi-section landing page for a fictional boxing gym. The design uses a dark navy and gold palette inspired by classic boxing aesthetics, with a full-screen hero section and a card-based course catalog.

## Features

- **Hero section** — full-screen background image with overlay, headline, and tagline
- **Fixed navigation bar** — Home, Training, Gallery, and Join links
- **Courses section** — card grid of 6 training programs, each with a difficulty badge (Beginner / Intermediate / Advanced), description, duration, and session count
- **Consistent design system** — navy/gold color scheme and bold condensed typography throughout

## Built With

- Semantic HTML5
- CSS3 — Flexbox & Grid for layout, custom card components

## What I Practiced

- Structuring a multi-section page with semantic elements
- Hero sections with background images and overlays
- Building reusable card components
- Color-coded badges and a consistent visual theme
